# PROJETO WEBSITE VERTEX

**Autores:** Henrique Cassol e Otavio Kauan Cunha  

---

## 1. INTRODUÇÃO.

Este documento estabelece as diretrizes técnicas, arquiteturais e legais referentes ao repositório **WebSiteVertex**. O projeto compreende o desenvolvimento e a implementação da interface e das funcionalidades do website institucional Vertex, servindo como base técnica para suas respectivas aplicações.

---

## 2. Permissões e Condições de Uso.

É expressamente proibido o uso comercial ou malicioso deste repositório, produto de venda ou obtenção de lucro.
São permitidos forks do repositório: o projeto é aberto ao público para estudos e melhorias. Copiem, modifiquem e divirtam-se!

---

## 3. Linguagens e Tecnologias Utilizadas.

- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons e JavaScript (ES6+).
- **Backend:** Java 21, Spring Boot 3, Spring Security e JWT.
- **Banco de Dados:** PostgreSQL 16 e Flyway.
- **Infraestrutura & Ferramentas:** Docker, Docker Compose e Maven.
- **APIs Externas:** Overpass API (OpenStreetMap), BrasilAPI / Minha Receita e CNPJ Já (Consulta pública de CNPJ).
